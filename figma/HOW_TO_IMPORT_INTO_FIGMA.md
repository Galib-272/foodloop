## Import into Figma (2 minutes)
1. Open figma.com → **New design file**. Name it "FoodSphere AI".
2. Select all 13 `.svg` files in Finder and **drag them onto the Figma canvas** (or: main menu → File → Import…).
3. Each file becomes an editable group. Select one and press **Ctrl/⌘ + Alt + G** (Frame selection) to turn it into a frame, then rename it (e.g. "04 AI Surplus Forecast").
4. Arrange the frames in a row: desktop screens together, the two mobile screens next to them, the design system on its own page (right-click → Move to page → new page "Design System").
5. Font: the files use **Inter**, which Figma includes — no installation needed.

## Tips
- Double-click into a group to edit any text, colour or shape.
- To make reusable components (e.g. the primary button), select it in 00_Design_System → right-click → **Create component**.
- To add the colour styles: select a swatch in 00_Design_System → Fill → Style (four-dots icon) → **+ Create style**, name it like the swatch (Primary #1E523A, etc.).
